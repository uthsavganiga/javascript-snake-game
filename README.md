# 🐍 Snake Game

A browser-based Snake Game built from scratch using **HTML, CSS, and Vanilla JavaScript**. The project demonstrates core JavaScript concepts through an interactive game with real-time movement, scoring, timers, and collision detection.

## 🚀 Features

* Snake movement using keyboard arrow keys
* Random food generation
* Real-time score tracking
* High score tracking
* Game timer
* Collision detection
* Game-over state
* Restart functionality
* Interactive game interface

## 🛠️ Tech Stack

* **HTML5** — Structure and game interface
* **CSS3** — Styling and layout
* **JavaScript (ES6+)** — Game logic and interactivity

## 🧠 Key Concepts Practiced

* DOM manipulation
* Event listeners and keyboard events
* Arrays and objects
* Functions and game state management
* `setInterval()` and timers
* Collision detection
* Dynamic DOM updates
* Random number generation
* Conditional logic
